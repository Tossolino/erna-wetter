🔑 Speicher-Schlüssel

Der Schlüssel bleibt nur auf diesem Gerät gespeichert.

Wie bekomme ich den Schlüssel? (einmalig)
  1. Am PC oder Handy github.com/settings/personal-access-tokens/new öffnen und anmelden.
  2. Token name: Erna Einstellungen, Expiration: längste mögliche Laufzeit.
  3. Repository access: Only select repositories → erna-wetter.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Ganz unten Generate token, den angezeigten Schlüssel (beginnt mit github_pat_) kopieren und hier einfügen.

Der Schlüssel darf nur dieses eine Repository ändern. Nicht auf dem Tablet am Eingang eingeben.
